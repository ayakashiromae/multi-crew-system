# デザイン参考の引き方(design-reference)

Web ページ・サムネ・商品画像を作るクルーは、白紙から発想せず、まず拠点の実例カタログで
「同じ業態の型」を確認してから設計する。オペレーターは「型を外した独自案」より
「型に沿って題材に合わせた案」を通す。設計書には**参照した型と事例 URL を必ず書く**。

## 0. カタログの場所(拠点ローカル。git には入れない)

- 正本: `/home/shiromae/crew-out/review/design-study/`
  - `00_デザイン学習ノート_目次と要点.md`(横断の要点と使い方)
  - `01_LP.md` / `02_corporate.md` / `03_shop_ec.md`(Web サイト、業態別に各サイトの FV・セクション順・配色・書体・CTA)
  - `04_youtube_thumbnails.md`(サムネ 100 件超の型集計と全件表)
  - `05_instagram_product_images.md`(商品紹介画像 100 件超の型集計と全件表)
- 画像の参照用コピー: `/home/shiromae/crew-out/shots/design-study/{youtube,instagram}/`(コンタクトシート `sheet_NN.png` を Read で見る)
- 写し: Obsidian `副業/90_クルー報告/design-study/`
- カタログが無い/古い場合は、このスキルの「型」だけで設計し、報告に「カタログ未参照」と明記する。

## 1. 手順

1. 依頼の業態を特定する(下表のどれか。複数なら主となる 1 つ)。
2. 対応ファイルの「共通する型」節と、近い業態の事例 2〜3 件を読む(全件を読まない)。
3. 型に沿って「セクション順 / 主色+差し色 / 書体 / CTA 文言と位置 / 写真かイラストか」を先に決め、設計書の冒頭に書く。
4. 題材固有の要素(キャラ・世界観・商品)は、型を壊さない範囲で「装飾・コピー・カテゴリ構成」側に寄せる。
5. 設計書に「参照した型(番号)と事例 URL 2〜3 件」を書く。無いと検品で差し戻す。

## 2. Web サイトの型(業態別の要約)

| 業態 | FV | セクション順 | 配色 | 書体 | CTA |
|---|---|---|---|---|---|
| 見守り/IoT/サブスク LP | 安心コピー+家族/ペットの実写 | 不安の数値化→安心の可視化→機能 3 つ→料金(月額 1 数字+初期費用)→実績・継続率→声→FAQ→CTA | 白+製品色 1 色 | 丸ゴ寄り・大きめ | 資料請求・無料お試し(購入より前段) |
| 業務 SaaS/管理ツール LP | 業務課題を短文で言い切る | 実績ロゴ・導入社数→課題→機能→事例の削減数字→料金は別ページ誘導→サポート→CTA | 青+白+グレー | 角ゴ | 無料で始める・資料 DL |
| 食品 D2C 単品通販 LP | 悩み共感+商品名+割引率を先出し | 権威付け(受賞・臨床・リピート率)→特徴・原材料→単品/定期の 2 段価格→声→比較表→限定感→FAQ→CTA | 白+赤か紺を CTA に集中 | ゴシック、商品名は明朝も可 | 今すぐ試す(赤で単独強調) |
| 建設・工務店コーポレート | 年数×実績件数、地域密着 | 新着→メッセージ→事業内容→施工実績(写真グリッド)→強み→会社概要→採用 | 紺/グレー+オレンジ/アンバー | 力強い角ゴ | 採用は常設ナビ+先輩インタビューの二重導線 |
| 人材派遣・紹介コーポレート | 求職者向け/企業向けの 2 ボタン | 特長→求人検索/サービス→企業向け→求職者向け→スタッフの顔→会社概要 | ネイビー+柔らかいピンク/水色 | やや丸みのあるゴシック | 2 導線を FV 直下で分ける |
| サウナ・温浴の店舗サイト | 施設/自然写真のスライダー+一言 | コンセプト/ストーリー→施設・サービス→料金→アクセス→予約 | モノトーン+写真由来の 1 色 | ゴシック、見出しだけ太め | 控えめに複数配置(押し売りしない) |
| 和菓子・老舗の店舗サイト | 商品写真+一言、創業年を即明示 | ブランド紹介→代表商品 1 点→季節商品→カテゴリ→お知らせ→店舗情報 | 白/生成り+深紅/藍/金/深緑 1〜2 色 | 見出し明朝 | ヘッダー・商品末・フッターの多重配置、Instagram/LINE 導線 |
| ゲーム風・世界観 EC | 世界観イラスト+一言 | カテゴリアイコン→新着・ランキング→特集(クエスト風)→会員→フッター | 濃紺/黒+金・赤をバッジに限定 | ドット風はロゴ・見出しのみ、価格は通常フォント | 価格直下に「カートに入れる」、カートはヘッダー固定 |

注: 上表の配色・書体は本文取得(WebFetch)からの読み取りと業界傾向からの推定を含み、画面キャプチャ・CSS による実物確認はしていない。実物を確かめるときは事例 URL を開く。第 3・4 節(サムネ・商品画像)は実画像の目視に基づく。

横断の原則: (1) FV は「一言+第三者性の数字」、(2) 白ベース+主色 1+差し色 1、(3) CTA の温度は業態で決める、
(4) 世界観は購入導線に持ち込まず装飾・コピー・カテゴリ構成に寄せる、(5) 感情は実写・仕組みはイラスト・キャラは小さく親しみ担当。

## 3. YouTube サムネイルの型(実例 140 件の集計)

- **文字数は 9〜16 字が 6 割**(1〜8 字が 25%、17 字超は 2ch・切り抜きの引用系のみ)。白文字+黒縁が基本、差し色は赤か黄の 1 色に絞る。
- 出現の多い型: (1) タイトルのみ+マスコット添え、(2) 疑問形+図解/イラスト、(3) 会話吹き出し+2 キャラ、(4) 資料写真+タイトル、(5) シリーズ数字バッジ+筆文字/大タイトル(「○分で分かる」系)、(6) スレ引用+煽り結論(www)。
- 再生数上位は「情報量を絞った記号的なサムネ」(数字バッジ、文字最小、タイトルのみ)が食い込みやすい。
- ジャンルで型がほぼ固定: 2ch まとめは「スレ引用+煽り結論」、歴史 10 分は「シリーズ数字バッジ+大タイトル」。

| 用途 | 推奨型 | レイアウト | 文字量 | 色 |
|---|---|---|---|---|
| 解説 本尺(10 分前後) | 大文字フレーズ+キャラ片側 / 疑問形+簡易図解 | 右 1/3〜2/5 にキャラ、左〜中央に太字 2〜3 行 / 上部に「なぜ○○?」、下半分にシルエット・矢印 | 8〜14 字 / 12〜20 字 | 暗背景+白黒縁+赤か黄 1 色 |
| short(縦) | 数字ドン+短フレーズ / 顔アップ+驚き | 中央に巨大な数字か 1 語、上下に補足 / 6〜7 割を顔、上部にフック | 20 字以内 / 8〜14 字 | 暗背景+白+黄/橙 1 色 |
| 切り抜き | 会話吹き出し+2 キャラ / 顔アップ+一言 | 上下 2 段の吹き出し、左右にリアクション顔 / 表情アップ+上部に断定一言 | 20〜30 字 / 8〜12 字 | 白黒ベース+赤か水色 |
| 2ch まとめ | フレーズ+chibi+煽り結論(www) | 中央に本文、最下部に黄/虹縁の煽り、chibi 1〜2 体 | 20 字前後 | パステルグラデ背景 |

コンタクトシートは `shots/design-study/youtube/sheet_01〜07.png`、全件表(id・型・文字数・主色・URL)は `04_youtube_thumbnails.md`。

## 4. Instagram 向け商品紹介画像の型(実例 124 枚の集計。バナーギャラリー由来が多く、広告寄りの型が強めに出ている)

- 出現の多い型: (1) 商品ドン+一言(25%)、(2) 商品ドンのみ・文字なし(EC 出品サムネ型、22%)、(3) 人物写真+商品の使用シーン(17%)、(4) テキスト全面のセール訴求(8%)、(5) イラスト+特典訴求(7%)。価格・割引・数字を画面内に出すのは 44%。
- 文字は「複数要素を全面に散らす」か「文字なし」の二極。1 文だけは 11%。
- カテゴリ傾向: 食品は什器盛りの俯瞰写真+商品由来の 1 色、雑貨は余白の大きいフラットレイで文字なし、サービスは人物の表情+青/紺で安心感、コスメは白背景+成分/実績の数字。

| 用途 | 推奨型 | レイアウト | 文字量 | 色 |
|---|---|---|---|---|
| 食品(和菓子・飲料) | 商品ドン+ラベル / 季節訴求+クーポンバッジ | 商品を 60〜70% の大きさで中央、上部 15% の帯に商品名、右上に小バッジ / 上部に季節ワード、中央に商品、下部に円形バッジ | 商品名 1 文+バッジ 1 語 / タイトル 1 文+クーポン | 白〜生成り+商品色 1 色 / 季節の淡いグラデ |
| 雑貨 | フラットレイ文字なし / 着用シーン文字なし | 商品を 40〜50% で中央、余白大、真俯瞰か 45 度 / 無地背景でバストアップ〜全身 | なし | グレー・生成り・木目のニュートラル |
| サービス(見守り・管理ツール) | 人物+一言+CTA 帯 / 実績・特典の数字ドン | 人物を半分〜全面、下部に一言、最下部に CTA 帯 / 上にロゴ、中央に大きな数字、下にアイコン列 | 1 文+CTA / 数字+補足+ラベル | 白+ブランド色 1 色(安心系は青/紺) |

コンタクトシートは `shots/design-study/instagram/sheet_01〜07.png`、全件表(番号・サイト・カテゴリ・型・文字量・主色・URL)は `05_instagram_product_images.md`。

## 5. 書体の指定(モリサワ書体を実名で)

この拠点は Morisawa Fonts(スタンダードプラン=デスクトップフォント契約)を使える。設計書の書体欄は「角ゴ/丸ゴ」の抽象指定ではなく、次の表の書体名で書く。詳細と根拠は `06_morisawa_fonts.md`。

| 用途 | 見出し | 本文 | 強調・数字 |
|---|---|---|---|
| 見守り/IoT LP・人材派遣 | UD新ゴ EB/H | UD新ゴ R/M | UD新ゴ B/DB |
| 業務 SaaS LP・建設・サウナ | 新ゴ B/H | 新ゴ R/M | 新ゴ EB(建設の実績数字は ゴシック MB101 DB) |
| 食品 D2C LP・食品の商品画像 | A1明朝 B(商品名) | 新ゴ R | 新ゴ EB(価格・割引) |
| 和菓子老舗 | リュウミン B-KL / 黎ミン B | 黎ミン R | A1明朝 EB |
| ゲーム風 EC | 見出ゴ MB31(ロゴ・見出しのみ) | 新ゴ R(価格・注意書き) | 新ゴ EB |
| YouTube サムネ(全用途) | 新ゴ EB/H(short は UD新ゴ EB) | ― | 見出ゴ MB31(数字バッジ)、2ch まとめの煽りは じゅん 太め |
| 解説動画テロップ | 新ゴ M/B(字幕)、見出ゴ MB31(題名帯)、リュウミン/黎ミン(章題カード) | ― | 新ゴ EB / UD新ゴ EB |

ライセンスの扱い(公式ページの要約。条文原文は未確認):
- 可: 商用利用、動画・映像への焼き込み、画像として書き出すサムネ・SNS 画像、Web デザインカンプの文字。
- 別契約: サイト本文を Morisawa 書体で配信する Web フォント利用(Web フォントプランが別途必要)。デスクトップ契約だけの案件では、実装フォントは Google Fonts 等の代替を併記する。
- 不可(サーバーフォントライセンスが別途必要): Linux のレンダサーバや自動生成パイプラインへのフォントファイル配置。解説動画パイプライン(Remotion)でモリサワ書体を使う案は、オペレーターの承認と別契約の確認が出るまで実装しない。
- 個別書体がスタンダードプランに含まれるかは書体見本ページで「含まれます」表示を確認する(調査時点で実地確認したのは ゴシック MB101 R のみ)。

## 6. 納品物に含めるもの

- 設計書の冒頭: 業態 / 参照した型 / 事例 URL 2〜3 件 / セクション順 / 配色 / 書体 / CTA。
- 検品(qc-final)は「型を外していないか」「事例 URL が実在するか」を見る。独自性より型の順守を優先する。
