# sfx-hunt — 動画素材のマルチクルー捜索

殿(しろまえ)の動画制作(YouTube・収益化あり)向けに、フリー素材を並列捜索してクルー側で決めて納品するスキル。候補一覧を返して選ばせるのではなく、こちらで選び、DLし、短い納品報告だけ出す。

## 保存先(固定)

ルート: `D:\Video`(自宅PC。Cowork からはリンク済みPCのこのフォルダへ commit、未接続なら D:\Video へのアクセスを要求する。WSL2 クルーからは `/mnt/d/Video`)

| サブフォルダ | 入れるもの |
|---|---|
| BGM/ | 音声で尺が **10秒を超える** もの |
| SE/ | 音声で尺が **10秒以下** のもの |
| movie/ | 動画素材(mp4/mov/webm など) |
| photo/ | 静止画(png/jpg/svg/gif など。いらすとや含む) |

- 音声の振り分けはサイトのカテゴリではなく実測の尺で決める。DL後に `ffprobe -v error -show_entries format=duration -of csv=p=0 <file>` で測り、10.0秒超なら BGM、それ以外は SE。ffprobe が無い環境ではサイト表記の尺で代用し、報告に「尺はサイト表記」と書く
- サブフォルダはこの4つ以外作らない。動画ごとの区別はファイル名の接頭辞で行う
- ファイル名: `<接頭辞>_<用途>_<元サイト>.<ext>`。接頭辞は殿が動画名を言っていればそれ、無ければ YYYYMMDD(JST)。例: `20260902_door_close_soundeffectlab.mp3` / `sukatto07_ojisan_angry_irasutoya.png`
- 同名ファイルがあれば上書きせず `_2` を付ける

## 前提・固定条件

- 用途: YouTube 収益化チャンネル。→ **商用利用OK が必須**。クレジット表記不要を優先し、表記必須の素材を使った場合は納品報告に「概要欄に貼る表記文」を添える
- 殿への質問は最小限。「雑に探して」と言われたら雑でよい。台本があれば読んで必要な素材を自分で洗い出す

## 捜索先(この順で優先)

効果音・BGM:

1. 効果音ラボ (soundeffect-lab.info) — 商用可・クレジット不要。直リンクDL可
2. Springin' Sound Stock (springin.org/sound-stock) — 商用可・クレジット不要。ポップ/ゲーム系に強い
3. DOVA-SYNDROME (dova-s.jp) — BGMの主力。商用可だが**作者ごとの規約あり**。作品ページの利用規約を必ず確認
4. OtoLogic (otologic.jp) — CC BY 4.0。クレジット表記必須なので他で見つからない時の補欠
5. 補欠: Pixabay Sound Effects/Music / Freesound(CC0 のみ採用) / Mixkit

画像・イラスト:

1. いらすとや (irasutoya.com) — 商用可。**1動画あたり20点まで**無料、超えると有料。件数を数えて報告する
2. **実写写真(店舗・実在の物・風景)は Wikimedia Commons (commons.wikimedia.org) を第一調達先にする**(殿方針 2026-09-02)。
   カテゴリ表示ではなく**個別ファイルページのライセンス欄を必ず確認**。優先順: CC0/PD > CC BY(表記のみ) > CC BY-SA(継承義務を報告に明記)。
   帰属表記1行(「写真: ○○氏 (CC BY x.x) via Wikimedia Commons」)を納品報告と台帳に必ず残す。
   企業公式サイトからの画像転載は不可(私的使用超えの複製は規約違反が通例)
3. Pixabay / Unsplash — 商用可・クレジット不要
4. photoAC / illustAC — 要会員・1日DL上限あり。ログインが必要な場合は殿に投げる
5. O-DAN (o-dan.net) — 海外ストック横断検索の入口として使う

動画素材:

1. Pixabay Video / Pexels Video — 商用可・クレジット不要
2. Mixkit — 商用可。規約ページを確認

ライセンスは上記を目安にしつつ、**実行時に各素材ページの規約を再確認する**。サイト側の改定はよくある。

## 手順

### 1. 要件の洗い出し(本体クルー)

- 台本・シーン一覧があれば読み、必要な素材を 種類 / 用途シーン / 尺の目安 / 雰囲気 のリストにする(例「決定音・0.5秒・軽め」「ループBGM・60秒・コミカル」)
- 単発の依頼(「ドアの閉まる音」)ならその1件をリスト化
- 接頭辞(動画名)が分かれば使う。分からなければ日付。聞かない

### 2. 並列捜索(サブエージェント / ワーカークルー)

- リストを **素材ごと**(多いときはサイトごと)に分割し、Agent ツールまたはワーカークルーへ同時に投げる。目安は 3〜6 並列
- 各エージェントへの指示テンプレ:

  > 「〇〇の音(尺△秒・雰囲気□□)」を上記サイトから探す。条件: 商用可・YouTube収益化可・できればクレジット不要。最良の1本を決めて、URL / ファイル直リンク / 尺 / ライセンス(表記要否) / 選定理由1行 を返す。見つからなければ代替案(似た音)を1本

- エージェントは候補を並べない。**決める**。迷ったら「クレジット不要 > 尺が合う > 質」の順で判定
- ブラウザ操作が必要なサイト(DOVA 等)は WebFetch で規約と直リンクを取り、DLは本体に任せる

### 3. 選定チェック(本体クルー)

- 戻ってきた結果を横断して、**雰囲気の統一**(同じ動画内でトーンがバラつかないか)、**いらすとや20点上限**、**クレジット必須素材の混入**を確認
- NG があればそのエージェントに差し替えを再依頼(1回まで)。それでも無ければ「無し」と報告して殿に投げる

### 4. ダウンロードと振り分け(直列)

- ブラウザは1つなので DL は本体が順番に行う。Cowork: 内蔵ブラウザで DL → `D:\Video\<サブフォルダ>` へ commit。WSL2 クルー: `curl -L -o` で直リンク取得 → `/mnt/d/Video/<サブフォルダ>`(直リンク不可のサイトはブラウザ経由 or 殿に依頼)
- 音声は一旦作業フォルダに落として ffprobe で尺を測ってから BGM/SE に振り分ける。壊れていれば差し替え
- 規約で「再配布禁止」の素材を git リポジトリや共有フォルダにコミットしない。D:\Video 内のみ

### 5. 納品報告(短く)

以下の形式で1メッセージ。前置き不要。

```
納品: D:\Video
- SE\20260902_door_close_soundeffectlab.mp3 — ドアが閉まる / 0.8s / 表記不要
- SE\20260902_kettei_springin.mp3 — 決定音 / 0.4s / 表記不要
- BGM\20260902_comical_loop_dova.mp3 — 日常シーン用ループ / 1:32 / 表記不要(作者規約確認済)
- photo\20260902_ojisan_angry_irasutoya.png — 怒るおじさん / いらすとや(3/20点)
要対応: OtoLogic 1件使用 → 概要欄に「効果音: OtoLogic (CC BY 4.0)」
見つからず: 「2chの書き込み音っぽいSE」→ タイピング音で代用、要確認
```

## やらないこと

- 有料素材の購入、会員登録、ログイン(必要なら殿に依頼する)
- 候補を10個並べて選ばせる(頼まれた時だけ試聴ページを作る)
- 規約未確認のまま「商用可」と書くこと
- D:\Video の4サブフォルダ以外へ書き込むこと、新しいサブフォルダを作ること

## 口調

ルーチン作業なのでクルーくん成分は多めでよい(「スキャン通った」「タスク完了」程度)。ただし納品報告の本文と表記文は通常モード。
