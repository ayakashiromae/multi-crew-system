# 切り抜き演出の提案手順(kirinuki-direction)

台本(字幕キュー)を作るクルーは、字幕の文言と強調種別だけで納品してはならない。
オペレーターは「字幕だけ」を工夫不足として差し戻す。以下の演出を**キュー単位で提案**し、
可読台本の「演出」列に必ず書く。判断に迷う箇所は候補を併記して止まらず進める。

## 1. 演出の語彙(キュー JSON の `fx` / `sfx` / `replays` / `outro` に対応)

| 演出 | いつ使う | 目安 |
|---|---|---|
| 強調A(黒太字・揺れ) | 短い反応語・断言・ツッコミ(5 文字前後、1 行) | 60 秒に 4〜7 個 |
| 強調B(赤明朝) | 冒頭の問いかけ・決め台詞・オチ・言い切りの名言 | 60 秒に 3〜5 個 |
| 強調C(白大) | 一言の返事・合いの手 | 0〜2 個 |
| wwww(強調A) | 笑い声・失笑・爆笑の区間。字幕が無い笑いは必ず草にする | 笑いごと |
| 効果音 | 断言・ツッコミ=バシッ/ドン系、気づき・名言=ポーン/ひらめき系、失敗=ずっこけ、拍手=歓声 | 強調A/B の半数程度 |
| パンチイン(`punch`) | 強調A/B の表示中に 1.15 倍ズーム | 強調と同時 |
| 集中線(`lines`) | 強調Aと、最大の決め台詞 | 強調Aと同時 |
| リプレイ(`replays`) | 名言・オチ。直後に同区間をアップ(1.6〜2.0 倍)+0.5 倍速で繰り返す。効果音を頭に添える | 60 秒に 1〜2 回 |
| 表示延長 | 短すぎる一言(0.5 秒未満)は次の字幕の直前まで伸ばす | 該当キュー |
| 終端カード(`outro`) | 最終フレームを 1.5〜2 秒静止させ「結論:○○」など一言で締める | 1 本に 1 回 |

## 2. 手順

1. 文字起こし(単語タイムスタンプ付き)を 1〜2 行・1〜3 秒のキューに割る。無音・笑いの区間を洗い出す。
2. 各キューに強調種別を付け、上の表に従って `fx` / 効果音 / リプレイ候補を割り付ける。
3. 効果音は素材フォルダ(identity の SE 置き場)の在庫から選ぶ。合うものが無ければ sfx-hunt スキルで探す(在庫確認をせずに「無い」と言わない)。
4. 可読台本(表形式、YAML/JSON 禁止)に「演出」列と「聞き間違い候補」表を付けて outbox へ。機械用 JSON は別ファイル。
5. 提案は「やりすぎ」側に倒してよい。オペレーターが削る方が、足りないものを指摘させるより速い。

## 3. 禁止・注意

- 字幕の文言は話者の発話どおり。意味を変えない。改行を数字・語の途中に入れない。
- 固有名詞(店名・人名)はスキルに書かない。名札の文言は依頼ごとに確認する。
- 演出の実装(レンダラの機能)が無いものを提案してもよいが、「未実装」と明記する。
